# DDDどうじょう 📐

**ドメイン駆動設計 (Domain-Driven Design)** を基礎から実務レベルまで身につけるブラウザ学習アプリです。左に教科書（コード例つき）、右に一問一答（4択）。答えるとその場で判定と解説が出ます。

**このアプリは「概念の正確な理解と、設計判断の反復訓練」を担当します。** DDDの4択は暗記ではなく「この処理はどこに置くべきか」「この境界はどう切るべきか」という判断問題が中心です。コード例は Go / Python で書かれています。

## 使い方

```sh
cd ddd
go -C app run .
```

ブラウザで <http://127.0.0.1:8087> を開いてください。必要なのは [Go](https://go.dev/dl/) 1.22+ だけです。

## 構成（全16章）

| パート | 章 | 内容 |
|---|---|---|
| 導入 | 第1〜2章 | DDDの全体地図・ユビキタス言語 |
| 戦略的設計 | 第3〜5章 | 境界づけられたコンテキスト・コンテキストマップ・サブドメインと蒸留 |
| 戦術的設計 | 第6〜11章 | エンティティ・値オブジェクト・集約・ドメインサービス/イベント・リポジトリ |
| アーキテクチャ | 第12〜14章 | アプリケーションサービス・ヘキサゴナル/オニオン/クリーン・CQRS/ES |
| 実践 | 第15〜16章 | イベントストーミング・ECサイト設計演習・アンチパターンと現実解 |

- 全問正解でチャプタークリア ✅。間違えた問題は **にがて帳** に自動記録され、ワンクリックで解き直せます
- 設計力は「自分の言葉で説明できるか」で決まります。🎤 **口頭試問**（AIが別角度の設計問答を出題・採点）を毎章使うのがおすすめです

## AI の先生（ローカルに [Claude Code](https://claude.com/claude-code) がある場合）

「🙋 質問」からいつでも使えます。なくても学習機能はすべて使えます。

| 機能 | 何をしてくれるか |
|---|---|
| 💬 質問 | いま学んでいるチャプターの文脈で、コード例と原語つきで回答 |
| 🎤 口頭試問 | 「なぜそう設計するのか」を記述させて採点。設計の言語化力を鍛える |
| 📝 弱点まとめ | 全誤答・全質問を分析し、「苦手トピックトップ3・次にやること」をノート化 |
| 🎯 専用復習問題 | 誤答の多い論点を自動特定し、別角度の類題で専用章を生成 |
| 📰 最新動向ノート | AI が Web 検索で DDD コミュニティの動向・書籍・実践記事を調べて出典付きノートを作成 |

AI の利用量はリポジトリ直下の `ai-config.json` で管理できます（`-1`=無制限 / `0`=停止 / 正の数=1日の上限）。

## 教材データ

正データは `lessonNN/chMM.json`（教科書 `text` + 4択 `quiz`）。編集後は `go run ./tools/coursegen` で検証します。

本教材はオリジナルの解説と問題で構成されています（特定書籍の転載ではありません）。
